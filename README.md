# Portofolio

Website portofolio dan dashboard admin untuk mengelola profil, proyek, skill, dan artikel blog. Dibangun dengan Next.js App Router, React, TypeScript, Tailwind CSS, serta Supabase.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000). Perintah lain yang tersedia:

```bash
npm run lint
npm run build
npm start
```
